# 加賀指ぬきデザインツール

伝統柄（四つ鱗・市松・青海波）や任意の画像を読み込み、パーツごとの色を自由に変更・保存できる JavaFX 製のデザインツールです。

## 動作環境

- Java 21 以降（JavaFX ランタイムを含む）

## 起動方法

```bash
java --module-path <JavaFXのlibパス> --add-modules javafx.controls,javafx.swing App
```

## 画面構成

| 画面 | 内容 |
|---|---|
| ホーム画面 | 新規作成・画像読み込みの入口 |
| 編集画面 | 色の変更、Undo、バージョン保存、PNG書き出し |

---

## 操作手順

### 1. ホーム画面

- **新規作成**：四つ鱗／市松／青海波の柄から選んで編集を開始
- **読み込み**：
  - 画像読み込み（PNG / JPG ファイルを開く）
  - クリップボードから（コピーした画像を貼り付けて開始）

### 2. 編集画面

| 操作 | 説明 |
|---|---|
| カラーピッカー（色１〜４） | 各パーツの色を変更。柄の元の4色に対応 |
| 判定幅スライダー | 色の同一性判定の許容範囲（Lab色空間の距離）を調整。広げるほど近似色もまとめて置換される |
| スポイト（画像クリック） | クリックした位置の色をその場でピッカー表示し、置換色を選択できる |
| 色リセット | すべての色を読み込み時の状態に戻す |
| 戻す（Undo） | 直前の操作を1つ取り消す（最大20手分） |
| 現在の状態を保存 | 作業中の画像を3つある保存スロットの1つに記録し、下部にサムネイル表示 |
| サムネイルクリック | 保存済みのバージョンをその場で呼び出す（未保存の枠はクリック不可） |
| 保存 | 現在の画像をPNGファイルとして書き出す |
| 中止 | ホーム画面へ戻る（編集中の場合は確認ダイアログを表示） |

### 3. バージョン管理（保存スロット）

- スロットは **3つ**（Ver.1〜Ver.3）
- 「現在の状態を保存」を押すたびに、空いているスロット→古いものから順に上書き（リングバッファ方式）
- サムネイルにマウスを乗せると保存日時がツールチップで表示される
- 新しい画像・柄を読み込むと、保存スロットとUndo履歴はすべてリセットされる

---

## 主な機能一覧

- 柄のプリセット読み込み（四つ鱗／市松／青海波）
- 画像ファイル／クリップボードからの読み込み
- Lab色空間ベースの色置換（近似色をまとめて変更可能）
- スポイトによる色選択
- Undo（最大20手）
- 3スロットのバージョン保存・呼び出し
- PNG形式での書き出し
- ウィンドウサイズに応じて画像・操作パネルが自動でリサイズ（どのサイズでも全ツールが画面内に収まる）

## 注意事項

- 色置換はバックグラウンド処理のため、処理中は各種ボタンが一時的に無効化されます
- 保存スロットはアプリ内メモリ上の一時保存です。アプリを閉じると消えるため、確定した画像は「保存」でPNG書き出ししてください
